# Project_Description
This project implements a Human Pose Estimation and Key Point Detection system using Python, OpenCV, and MediaPipe. It detects human body landmarks from images and videos and visualizes them as skeletal connections, enabling applications such as posture analysis, fitness tracking, and activity recognition.
# Features
1. Detects 33 human body landmarks
2. Supports image and video processing
3. Draws pose landmarks and skeletal connections
4. Generates processed output videos
5. Lightweight and efficient implementation
# Technologies Used
1. Python
2. OpenCV
3. MediaPipe
4. Google Colab
# Workflow
1. Upload an image or video.
2. Read the input using OpenCV.
3. Convert the image from BGR to RGB format.
4. Apply MediaPipe Pose for landmark detection.
5. Draw landmarks and connections.
6. Display or save the output.
